LINKS HIGHLIGHTER · ПОСІБНИК І ДЕМО

Перевірте, як розширення аналізує посилання

Тут можна встановити Links Highlighter, швидко розібратися з основними кнопками й перевірити приклади. Тестові посилання не відкривають сторонні сайти. Вбудована сторінка CERN завантажується окремо й може бути недоступна.

Встановлення

Завантажте готову версію з публічного репозиторію. Вихідний код для встановлення не потрібен.

  1. Натисніть Code → Download ZIP.
  2. Розпакуйте архів і залиште папку в постійному місці.
  3. У Chrome відкрийте chrome://extensions, увімкніть Developer mode, натисніть Load unpacked і виберіть розпаковану папку, де лежить manifest.json.
  4. Щоб швидше відкривати розширення, закріпіть його через меню Chrome за значком пазла.

Щоб оновити розширення, замініть файли в цій папці вмістом нового архіву й перезавантажте розширення на сторінці chrome://extensions. Для роботи в режимі Incognito відкрийте Details розширення та ввімкніть Allow in incognito.

Швидкий початок

  1. Відкрийте Links Highlighter через закріплену іконку або меню розширень Chrome.
  2. Для першої перевірки виберіть All у фільтрах Link type і Follow type.
  3. Натисніть Highlight, щоб знайти й підсвітити посилання. Reset прибирає підсвітку й ставить моніторинг на паузу в цій вкладці.
  4. Відкрийте Full info, щоб переглянути список. Скористайтеся пошуком, лупою біля посилання або кнопкою Export CSV.
Додаткові приклади: Щоб побачити посилання з груп Other, Suspicious, Unknown destination, JavaScript links або Iframe links, увімкніть відповідні прапорці в Include these groups. Для Unknown destination також потрібен прапорець JavaScript links.

Highlight, Reset і моніторинг
HighlightСканує сторінку з поточними фільтрами. Якщо ввімкнено Monitor new or changed links, також запускає моніторинг.
ResetПрибирає підсвітку й ставить моніторинг на паузу лише в цій вкладці. Налаштування не змінюються. Натисніть Highlight, щоб продовжити.
Автоматичний запускHighlight links when a page loads сканує сторінку після завантаження. Якщо ввімкнено лише моніторинг, після перезавантаження натисніть Highlight. Якщо ввімкнено обидва параметри, сканування й моніторинг почнуться автоматично.
МоніторингПісля запуску відстежує нові або змінені посилання. Якщо ввімкнути його після Highlight, він почне працювати на цій сторінці одразу.
Full info, пошук і CSV
СписокFull info показує знайдені посилання незалежно від того, які з них підсвічені. Посилання у вбудованих сторінках зібрані в окремій групі Iframe.
Пошук і лупаПошук знаходить посилання за текстом або адресою. Натисніть лупу, щоб перейти до посилання на сторінці; приховане посилання тимчасово стане видимим.
КопіюванняКнопка копіює адресу посилання. У групі Iframe можна скопіювати адресу вбудованої сторінки.
Export CSVЗавантажує всі знайдені посилання з доступних сторінок, навіть якщо пошук приховав їх у списку. Таблицю можна відкрити у програмі для роботи з таблицями. Для посилань на основній сторінці поле Frame URL порожнє; для посилань у фреймі в ньому вказана адреса цієї сторінки.
Налаштування й винятки
Тема й кольориЗа замовчуванням тема popup відповідає темі комп’ютера. У Settings → Appearance можна вибрати Classic, Light або Dark та змінити кольори підсвічування.
Виняток для сайтуВиняток вимикає підсвічування на сайті. У Settings → Site exceptions введіть домен або URL і натисніть Add. Або натисніть Add current site to exceptions біля кнопок сканування.
Піддомениexample.com стосується лише цього домену. *.example.com — його піддоменів, але не самого example.com. Щоб знову підсвічувати посилання, видаліть виняток зі списку.
ЗбереженняНалаштування та винятки зберігаються в Chrome Sync і можуть синхронізуватися з іншими пристроями вашого профілю Chrome.
Що означають категорії
InternalПосилання на поточний сайт або його основний домен.
SubdomainПосилання на піддомен того самого основного домену, наприклад blog.example.com.
ExternalПосилання на інший сайт.
Dofollow / nofollowСтатус визначається за атрибутом посилання. Позначка nofollow означає nofollow; без неї — dofollow.
OtherАдреси електронної пошти, телефону й SMS. Цю групу потрібно ввімкнути окремо.
SuspiciousНеповна, некоректна або непідтримувана адреса. Це не оцінка безпечності сайту.
Unknown destinationРозпізнано JavaScript-перехід, але його адресу неможливо визначити наперед.
JS / IFRAMEБейджі показують, що посилання пов’язане з JavaScript або розташоване у вбудованій сторінці.

Результат для Internal і Subdomain залежить від адреси, з якої відкрито цю сторінку.

Якщо посилання не підсвічується
  • Щоб побачити всі звичайні приклади, виберіть All у фільтрах типу й статусу.
  • Для Other, Suspicious, Unknown destination, JavaScript і iframe увімкніть відповідні прапорці.
  • Перевірте, чи Chrome дозволив розширенню працювати на сайті, і перезавантажте вкладку після зміни дозволів.
  • Розширення не працює на сторінках Chrome на кшталт chrome://extensions. Деякі вбудовані сторінки також можуть бути недоступні.
  • Якщо повідомлено про неповні результати, розширення не змогло прочитати один або кілька фреймів. Інші доступні посилання все одно перевіряються.

Посилання у вбудованих сторінках (iframe)

Увімкніть Iframe links, щоб побачити посилання у вбудованих сторінках. Локальний приклад нижче доступний без сторонніх сайтів. Вміст CERN залежить від мережі й може не завантажитися.

JavaScript-навігація (JS)

Увімкніть JavaScript links, щоб побачити ці приклади. Одні переходять на фрагмент цієї сторінки, в інших адресу не можна визначити заздалегідь. Клік по тестових посиланнях не відкриває сторонні сайти.

Перевірка нових і змінених посилань

Щоб побачити зміни одразу, увімкніть Monitor new or changed links і натисніть Highlight. Кнопки нижче додадуть посилання або змінять його адресу, статус nofollow чи JavaScript-позначку. Щоб побачити JavaScript-позначку, увімкніть також JavaScript links. На цій сторінці зміна адреси на gastello.github.io визначається як Internal.

Додати нове посилання

Додасть нове зовнішнє посилання з rel="nofollow". Після появи розширення має підсвітити його як External — nofollow.

Тут з’явиться щойно додане посилання.

Змінити наявне посилання

Кожна дія змінює один атрибут. Очікувано: адреса перемикає External/Internal, rel — nofollow/dofollow, а onclick додає бейдж JS.

Тестове посилання (External — nofollow)

Початковий стан: зовнішня адреса, rel="nofollow", JavaScript-навігації немає.
