Перевірте, як розширення аналізує посилання

Відкрийте цю сторінку в Chrome, щоб перевірити Links Highlighter у реальному контексті сайту. Тут є приклади класифікації та покрокова довідка. Демопосилання безпечні: звичайне натискання не відкриває їхні адреси.

Завантаження та встановлення з GitHub

Цей спосіб встановлює розширення з вихідного коду репозиторію як unpacked extension.

  1. Завантажте ZIP-архів. Відкрийте репозиторій Links Highlighter на GitHub, натисніть Code → Download ZIP і дочекайтеся завантаження.
  2. Розпакуйте архів. Збережіть папку проєкту у постійному місці на комп’ютері. Не видаляйте й не переміщуйте її, поки користуєтеся розширенням. Для встановлення потрібна коренева папка проєкту, у якій лежить manifest.json.
  3. Додайте розширення до Chrome. Відкрийте chrome://extensions, увімкніть Developer mode, натисніть Load unpacked і виберіть розпаковану кореневу папку проєкту.
  4. Закріпіть іконку для зручного доступу. Відкрийте меню розширень за значком пазла на панелі Chrome і натисніть значок закріплення біля Links Highlighter. Після цього popup можна відкривати без пошуку в меню.
  5. Дозвольте роботу в анонімному вікні. Якщо плануєте користуватися розширенням в Incognito, на сторінці chrome://extensions відкрийте Details для Links Highlighter і ввімкніть Allow in incognito. Без цього дозволу Chrome не запускає розширення в анонімних вікнах.

Для оновлення замініть файли в тій самій папці встановлення на вміст нового архіву, потім натисніть кнопку перезавантаження на картці розширення в chrome://extensions. Не переміщуйте папку, з якої Chrome завантажує розширення.

Швидкий початок

  1. Відкрийте розширення. Натисніть закріплену іконку Links Highlighter у панелі Chrome. Якщо її ще не закріплено, скористайтеся меню розширень за значком пазла.
  2. Виберіть, що показувати. Для всіх прикладів установіть тип посилання й follow-статус у All. За потреби окремо ввімкніть Suspicious, Unknown destination, JavaScript links та Iframe links.
  3. Підсвітіть приклади. Натисніть Highlight. Кольори позначають тип і follow-статус, а бейджі JS та IFRAME — додаткові властивості посилання.
  4. Перегляньте результати. У панелі Full info шукайте посилання за текстом або URL. Кнопка Find on page прокрутить сторінку до нього й тимчасово виділить. Reset прибере позначки розширення.
  5. Увімкніть автоматизацію за бажанням. Highlight links when a page loads автоматично підсвічує сторінку після завантаження. Якщо разом із ним увімкнено Monitor new or changed links, нові зміни також відстежуються автоматично. Якщо ввімкнути лише real-time, натисніть Highlight, щоб почати спостереження.
Як показати Unknown і посилання у фреймах: Unknown — це JavaScript-навігація, адресу якої неможливо визначити наперед, а не оцінка безпечності. Для її підсвічування ввімкніть обидва фільтри: Unknown destination і JavaScript links. Якщо приклад розташований у фреймі, потрібен також фільтр Iframe links.
Налаштування, тема й винятки сайтів
ПоведінкаHighlight links when a page loads запускає перевірку після завантаження. Monitor new or changed links відстежує нові посилання та зміни href, rel і inline onclick. Для real-time без автопідсвічування натисніть Highlight; з обома опціями сканування й моніторинг запускаються одразу після перезавантаження сторінки.
Тема й кольориПід час першого запуску Light або Dark відповідає темі браузера. У Settings → Appearance можна вибрати Classic, Light або Dark, змінити кольори категорій і кольору Find on page. Restore default colors повертає стандартну палітру.
Додати винятокУ Settings → Site exceptions введіть домен або URL і натисніть Add. Або натисніть Add current site to exceptions біля кнопок сканування, щоб додати домен поточного сайту.
Точне зіставленняВиняток застосовується лише до точно вказаної назви домену незалежно від протоколу й порту. Наприклад, example.com не виключає shop.example.com — піддомени додаються окремо. На виключеному сайті сканування й скидання вимкнені.
СинхронізаціяНалаштування, кольори та винятки зберігаються через Chrome Sync і можуть синхронізуватися між браузерами з тим самим профілем Chrome.
Довідка: значення категорій і бейджів
InternalАдреса на тому самому домені, наприклад сторінка в межах gastello.github.io.
SubdomainАдреса на піддомені поточного домену. Тут media.gastello.github.io є піддоменом gastello.github.io.
ExternalАдреса на іншому сайті. У прикладах використано зарезервовані домени example.com, example.org та example.net.
Dofollow / nofollowТокен nofollow в атрибуті rel визначає follow-статус: якщо він є, посилання має статус nofollow; якщо немає — dofollow. Інші значення rel, зокрема ugc і sponsored, розширення не враховує для цього статусу.
SuspiciousПорожня або placeholder-адреса (наприклад, лише #), некоректний URL чи схема, яку розширення не класифікує як звичайне вебпосилання. Це технічна категорія, а не твердження, що сайт шкідливий; її фільтр працює окремо від Internal/External.
Unknown destinationРозпізнано JavaScript-навігацію, але її кінцеву адресу неможливо визначити статично. Працює окремо від Internal/External, але для підсвічування потрібен також фільтр JavaScript.
JS / IFRAMEБейджі показують додаткові ознаки й можуть поєднуватися з основною категорією; за наявності обох ознак відображається IFRAME + JS.

Приклади Internal і Subdomain залежать від адреси, з якої відкрито цю демосторінку. Якщо розмістити копію на іншому домені, частина результатів класифікації зміниться.

Якщо посилання не підсвічується
  • Перевірте тип посилання та follow-фільтр. Для всіх прикладів виберіть All.
  • Для Suspicious і Unknown увімкніть відповідний окремий фільтр. Для Unknown також потрібен фільтр JavaScript, а для прикладів у фреймі — iframe.
  • Переконайтеся, що Chrome дозволив розширенню доступ до цього сайту. Після встановлення або зміни дозволів оновіть вкладку.
  • Внутрішні сторінки Chrome та деякі вбудовані документи недоступні для розширень. Вміст зовнішнього фрейму додатково залежить від мережі й політики сайту.
  • Якщо статус повідомляє про неповні результати, розширення не отримало дані з одного чи кількох фреймів. Інші доступні фрейми все одно перевіряються.

Посилання у фреймах (iframe)

Розширення аналізує посилання у доступних HTTP/HTTPS-фреймах відносно адреси самого фрейму. Для позначок у локальному прикладі ввімкніть Iframe links; для Unknown додатково потрібні фільтри Unknown destination і JavaScript links.

JavaScript-навігація (JS)

Увімкніть JavaScript links, щоб додати ці приклади до результатів. Бейдж JS показує виявлений код навігації; він не замінює основний тип і follow-статус. Для визначеної адреси колір показує тип посилання, для невизначеної — колір Unknown. Якщо посилання також у фреймі, з’явиться бейдж IFRAME + JS.

Приклади переходять лише на фрагменти цієї сторінки або не виконують навігацію. Звичайний клік по демопосиланнях вимкнений.

Перевірка real-time: динамічні зміни

Ці кнопки додають посилання або змінюють href, rel та inline onclick. Увімкніть Monitor new or changed links. Якщо Highlight links when a page loads вимкнено, натисніть Highlight, щоб запустити спостереження. З обома ввімкненими режимами спостереження почнеться автоматично після перезавантаження. Щоб побачити бейдж JS після додавання onclick, увімкніть також фільтр JavaScript links. Посилання після зміни адреси стає Internal на gastello.github.io; результат буде іншим, якщо відкрити копію сторінки локально або розмістити її на іншому домені. Розширення відстежує появу посилань і зміни цих атрибутів, але не може виявити всі обробники, додані скриптами сторінки.

Додати нове посилання

Додасть нове зовнішнє посилання з rel="nofollow". Після появи розширення має підсвітити його як External — nofollow.

Тут з’явиться щойно додане посилання.

Змінити наявне посилання

Кожна дія змінює один атрибут. Очікувано: адреса перемикає External/Internal, rel — nofollow/dofollow, а onclick додає бейдж JS.
