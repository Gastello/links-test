Перевірте, як розширення аналізує посилання

Відкрийте цю сторінку в Chrome, щоб перевірити Links Highlighter на прикладах різних типів посилань, фреймів і динамічних змін. Нижче — повний посібник із налаштування, сканування, пошуку, експорту та винятків. Посилання в основному демоблоці й локальному iframe не переходять за адресами; зовнішній iframe CERN є сторонньою сторінкою.

Завантаження та встановлення з GitHub

Цей спосіб встановлює розширення з вихідного коду репозиторію як unpacked extension.

  1. Завантажте ZIP-архів. Відкрийте репозиторій Links Highlighter на GitHub, натисніть Code → Download ZIP і дочекайтеся завантаження.
  2. Розпакуйте архів. Збережіть папку проєкту у постійному місці на комп’ютері. Не видаляйте й не переміщуйте її, поки користуєтеся розширенням. Для встановлення потрібна коренева папка проєкту, у якій лежить manifest.json.
  3. Додайте розширення до Chrome. Відкрийте chrome://extensions, увімкніть Developer mode, натисніть Load unpacked і виберіть розпаковану кореневу папку проєкту.
  4. Закріпіть іконку для зручного доступу. Відкрийте меню розширень за значком пазла на панелі Chrome і натисніть значок закріплення біля Links Highlighter. Після цього popup можна відкривати без пошуку в меню.
  5. Перевірте доступ до сайтів. Chrome попросить дозволити розширенню читати й змінювати дані на HTTP/HTTPS-сайтах. Це потрібно для аналізу, підсвічування й моніторингу сторінок та доступних фреймів. Для роботи в Incognito окремо відкрийте Details розширення та ввімкніть Allow in incognito.

Для оновлення замініть файли в тій самій папці встановлення на вміст нового архіву, потім натисніть кнопку перезавантаження на картці розширення в chrome://extensions. Не переміщуйте папку, з якої Chrome завантажує розширення.

Швидкий початок

  1. Відкрийте розширення. Натисніть закріплену іконку Links Highlighter у панелі Chrome. Якщо її ще не закріплено, скористайтеся меню розширень за значком пазла.
  2. Виберіть, що підсвічувати. Для першої перевірки встановіть Link type: All і Follow type: All. Додаткові прапорці керують групами Other, Suspicious, Unknown destination, JavaScript links та Iframe links. Щоб побачити всі приклади цієї сторінки, увімкніть кожну групу.
  3. Запустіть перевірку. Натисніть Highlight. Розширення сканує доступні фрейми, підсвічує посилання відповідно до фільтрів і, якщо ввімкнено моніторинг, запускає його для поточної сторінки. Кольори відповідають типу та follow-статусу, а бейджі JS, IFRAME і hidden показують додаткові властивості.
  4. Знайдіть і дослідіть посилання. Full info показує повний список і лічильники незалежно від фільтрів підсвічування. Пошук фільтрує список за текстом або URL. Кнопка з лупою прокручує до посилання, за потреби тимчасово відкриває прихований контейнер і позначає ціль на 5 секунд. Кнопка копіювання копіює URL. Export CSV завантажує всі результати з доступних фреймів, а не лише видимі після пошуку.
  5. Налаштуйте автоматичну поведінку. Highlight links when a page loads запускає підсвічування під час завантаження документа. Monitor new or changed links відстежує нові посилання та зміни підтримуваних атрибутів. Якщо ввімкнено лише моніторинг, натисніть Highlight, щоб почати його на цій сторінці. Відкриття popup саме по собі не повторює підсвічування при завантаженні.
Як показати Unknown і посилання у фреймах: Unknown — це JavaScript-навігація, адресу якої неможливо визначити наперед, а не оцінка безпечності. Для її підсвічування ввімкніть обидва фільтри: Unknown destination і JavaScript links. Якщо приклад розташований у фреймі, потрібен також фільтр Iframe links.
Повний посібник: Highlight, Reset і моніторинг
HighlightЗапускає нове сканування з поточними фільтрами. Також поновлює моніторинг на цій сторінці, якщо Monitor new or changed links увімкнено. Повторне натискання запускає новий прохід, зокрема повторну спробу для фреймів, які могли не відповісти раніше.
ResetПрибирає підсвітку й зупиняє моніторинг лише на цій відкритій сторінці. Перемикач Monitor new or changed links залишається увімкненим. Щоб продовжити на цій сторінці, натисніть Highlight: сторінка просканується знову, а моніторинг відновиться, якщо його перемикач увімкнений. Після перезавантаження налаштування діють знову: якщо увімкнено Highlight links when a page loads, посилання підсвітяться автоматично, а моніторинг теж запуститься, якщо його перемикач увімкнений. Якщо увімкнений лише моніторинг, на новій сторінці натисніть Highlight.
Page on loadПідсвічує посилання після завантаження документа. Саме відкриття popup оновлює Full info, але не запускає page-load сканування повторно.
Real-timeПісля запуску спостерігає за доданими посиланнями та змінами href, rel і визначеними inline-обробниками навігації. Відстежує нові доступні iframe. Не виконує JavaScript сторінки та не бачить усі обробники, наприклад зареєстровані через addEventListener.
Режими разомЯкщо ввімкнути обидва параметри, після завантаження сторінка підсвічується й одразу починається моніторинг. Відкрита панель popup оновлює Full info, коли отримує повідомлення про зміни.
Повний посібник: Full info, Find і CSV
ЛічильникиПоказують усі виявлені посилання, включно з тими, які поточні фільтри не підсвічують. External frames — окремий лічильник елементів iframe із зовнішнім source URL, а не кількість посилань у них.
ГрупиЗвичайні посилання показані в групах Internal, Subdomain, External, Other, Suspicious і Unknown destination. Посилання з iframe зібрані в окремій групі Iframe з розгортанням окремо для кожного фрейму. JavaScript-посилання з відомою адресою показані в JavaScript, а не дублюються у звичайних групах.
Приховані посиланняБейдж hidden означає, що посилання було приховане стилями або атрибутом приховування під час сканування. Find on page тимчасово відкриває прихованих предків, прокручує до цілі й відновлює попередній стан після 5 секунд. Повторне Find або Reset також прибирає попередню позначку.
Find frameЛупа в заголовку iframe прокручує до iframe-елемента у його батьківському документі. Для посилання всередині iframe розширення спочатку знаходить посилання, а потім прокручує його батьківські iframe-контейнери.
КопіюванняКнопка копіює знайдений URL, а в групі iframe — адресу джерела фрейму. Якщо копіювання не вдалося, popup повідомить про помилку; Chrome може попросити дозволити clipboard.
CSVЕкспорт охоплює всі результати з доступних фреймів незалежно від пошукового запиту. Містить URL сторінки та фрейму, browser frame ID, фрагменти URL, тип і follow-статус, атрибути, доступний текст, видимість, JavaScript-джерело та CSS selector — вираз, який допомагає знайти елемент у DOM. Щоб скористатися ним, скопіюйте значення з CSV, відкрийте DevTools → Elements, натисніть Ctrl+F і вставте його. Якщо посилання у фреймі, клацніть правою кнопкою всередині цього фрейму й виберіть Inspect, а тоді шукайте selector: вміст фрейму має окремий DOM. У top-level посилань Frame URL порожній.
Налаштування, тема й винятки сайтів
ПоведінкаДва перемикачі керують page-on-load і real-time режимами окремо. Значки біля Add current site to exceptions показують, які опції збережені. Деталі роботи кнопок і паузи після Reset наведені вище.
Тема й кольориЗа замовчуванням popup автоматично перемикається між Light і Dark відповідно до теми системи. У Settings → Appearance → Popup theme можна зафіксувати Classic, Light або Dark: системна тема змінюється разом із налаштуванням ОС, а вибрана тема — ні. У Settings → Appearance → Link highlight colors налаштовуються кольори для типів посилань і follow-статусів, а також колір позначки Find on page. Enable glow effect вмикає або вимикає анімоване світіння навколо підсвічених посилань. Restore default colors відновлює палітру, не змінюючи перемикач світіння.
Додати винятокВиняток означає, що Links Highlighter не підсвічуватиме посилання на вказаному сайті. Щоб додати такий сайт, у Settings → Site exceptions введіть його домен або URL і натисніть Add. Або натисніть Add current site to exceptions біля кнопок сканування, щоб вимкнути підсвічування для поточного сайту.
Точне зіставленняexample.com виключає лише сам hostname, не його піддомени. Запис *.example.com виключає всі піддомени, включно з вкладеними (shop.example.com, a.shop.example.com), але не сам example.com. Протокол і порт не впливають на збіг. На виключеному сайті автоматичне й ручне підсвічування вимкнені; видаліть виняток, щоб повернути функцію.
СинхронізаціяНалаштування, кольори та винятки зберігаються через Chrome Sync і можуть синхронізуватися між браузерами з тим самим профілем Chrome.
Довідка: значення категорій і бейджів
InternalАдреса на тому самому hostname або на кореневому реєстрованому домені. Порожній href="", href="#" і фрагмент цієї сторінки класифікуються як Internal.
SubdomainАдреса на будь-якому піддомені реєстрованого домену, навіть якщо джерело вже розташоване на іншому піддомені. Наприклад, із blog.gastello.github.io посилання на media.gastello.github.io також є Subdomain.
ExternalАдреса на іншому сайті. У прикладах використано зарезервовані домени example.com, example.org та example.net.
Dofollow / nofollowТокен nofollow в атрибуті rel визначає follow-статус: якщо він є, посилання має статус nofollow; якщо немає — dofollow. Інші значення rel, зокрема ugc і sponsored, розширення не враховує для цього статусу.
OtherНепорожні адреси дій mailto:, tel: і sms:. Вони показані в окремому лічильнику й підсвічуються лише коли ввімкнено прапорець Other у Include these groups; це працює незалежно від вибору All, Internal або External.
SuspiciousЕлемент <a> без атрибута href, порожня адреса дії, некоректний URL або непідтримувана схема. Це технічна категорія, а не оцінка безпечності сайту.
Unknown destinationРозпізнано JavaScript-навігацію, але її кінцеву адресу неможливо визначити статично. Працює окремо від Internal/External, але для підсвічування потрібен також фільтр JavaScript.
JS / IFRAMEБейджі показують додаткові ознаки й можуть поєднуватися з основною категорією; за наявності обох ознак відображається IFRAME + JS.

Приклади Internal і Subdomain залежать від адреси, з якої відкрито цю демосторінку. Якщо розмістити копію на іншому домені, частина результатів класифікації зміниться. Піддомен визначається відносно реєстрованого домену, зокрема для sibling і вкладених піддоменів.

Якщо посилання не підсвічується
  • Перевірте тип посилання та follow-фільтр. Для всіх прикладів виберіть All.
  • Для Suspicious і Unknown увімкніть відповідний окремий фільтр. Для Unknown також потрібен фільтр JavaScript, а для прикладів у фреймі — iframe.
  • Переконайтеся, що Chrome дозволив розширенню доступ до цього сайту. Після встановлення або зміни дозволів оновіть вкладку.
  • Внутрішні сторінки Chrome та деякі вбудовані документи недоступні для розширень. Вміст зовнішнього фрейму додатково залежить від мережі й політики сайту.
  • Якщо статус повідомляє про неповні результати, розширення не отримало дані з одного чи кількох фреймів. Інші доступні фрейми все одно перевіряються.
  • Якщо після Reset сторінка знову підсвічується після натискання Highlight, це очікувано: Highlight запускає сканування заново. Саме відкриття popup не повинно повторно запускати page-on-load підсвічування.
  • Повідомлення про помилки шрифту в DevTools зазвичай належать сайту. Якщо Find не приводить ціль у видиму область, перевірте, чи не заблокував браузер скрипти для сторінки або її фрейму.
Дозволи та приватність
Доступ до сайтівДля аналізу, підсвічування, page-on-load і real-time Chrome надає розширенню доступ до HTTP/HTTPS-сторінок та дозволених фреймів. Chrome може показати широке попередження про доступ до сайтів.
Локальна обробкаКласифікація та CSV-експорт виконуються локально у браузері; посилання й вміст сторінок не відправляються на сервер розробника.
Збереження налаштуваньФільтри, кольори й винятки зберігаються у Chrome Sync та можуть синхронізуватися з іншими браузерами профілю. Дані прокрутки popup зберігаються лише для поточної сесії Chrome, окремо для вкладки та завантаження сторінки.
Обмеження ChromeРозширення не може працювати на сторінках chrome:// та деяких захищених сторінках. Вміст cross-origin iframe залежить від дозволів Chrome і політики сайту.

Посилання у фреймах (iframe)

Розширення аналізує посилання у доступних HTTP/HTTPS-фреймах: відносні адреси розв'язуються відносно документа iframe, а тип посилання класифікується відносно поточного сайту. У Full info посилання з iframe показані окремо від Internal, Subdomain та External. Для позначок у локальному прикладі ввімкніть Iframe links; для Unknown додатково потрібні фільтри Unknown destination і JavaScript links. Якщо сканування затримується, popup покаже доступні результати й попередить, що посилання всередині вбудованих фреймів можуть бути пропущені. Якщо ввімкнено Monitor new or changed links, відкладено завантажені доступні iframe підхоплюються автоматично, а відкрита панель оновлює лічильники. Повторне натискання Highlight також запускає нову спробу сканування всіх фреймів.

JavaScript-навігація (JS)

Увімкніть JavaScript links, щоб додати ці приклади до результатів. Статично аналізуються javascript: URL та поширені inline-обробники навігації, зокрема onclick, onkeydown і onpointerup. Бейдж JS показує виявлений код навігації; він не замінює основний тип і follow-статус. Для визначеної адреси колір показує тип посилання, для невизначеної — колір Unknown. Якщо посилання також у фреймі, з’явиться бейдж IFRAME + JS.

Приклади переходять лише на фрагменти цієї сторінки або не виконують навігацію. Звичайний клік по демопосиланнях вимкнений.

Перевірка real-time: динамічні зміни

Ці кнопки додають посилання або змінюють href, rel та inline-обробники навігації. Увімкніть Monitor new or changed links. Якщо Highlight links when a page loads вимкнено, натисніть Highlight, щоб запустити спостереження. З обома ввімкненими режимами спостереження почнеться автоматично після перезавантаження. Щоб побачити бейдж JS після додавання обробника, увімкніть також фільтр JavaScript links. Посилання після зміни адреси стає Internal на gastello.github.io; результат буде іншим, якщо відкрити копію сторінки локально або розмістити її на іншому домені. Розширення відстежує підтримувані inline-події, але не може виявити всі обробники, додані через addEventListener або властивості JavaScript.

Додати нове посилання

Додасть нове зовнішнє посилання з rel="nofollow". Після появи розширення має підсвітити його як External — nofollow.

Тут з’явиться щойно додане посилання.

Змінити наявне посилання

Кожна дія змінює один атрибут. Очікувано: адреса перемикає External/Internal, rel — nofollow/dofollow, а onclick додає бейдж JS.
